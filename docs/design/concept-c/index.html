C · Beacon

A tunnel seen head on: a ring with a centre. Each state changes the whole silhouette, and each change has one beat: a ripple when it drops, a turning arc while it retries, a pop when it is back. The dropdown is a small control panel, like the Wi-Fi and Sound menus.

Tray icon and state changes

Solid centre, broken ring, turning arc, no-entry disc. The shapes differ in mass, not in detail, so they hold up at 16 px. Motion is a pulse. Each change plays once and then holds still; only Reconnecting loops. With Reduce Motion on, states swap with no animation and Reconnecting shows its still frame.

Dropdown in every state

A frosted panel of tiles. The status tile is the headline; a tinted tile appears only when something needs the user. The rest behaves like menu rows. The blur is real: backdrop-filter over a wallpaper and a terminal window.

Setup and settings

No wizard and no tabs: setup is one page of three cards, settings is one page of grouped rows. No field ever asks for a social platform password or code, and the private key is never shown.

Strengths and risks

Compare with the other two on the overview.

Strengths

  • Easiest to read at a glance: each state has its own silhouette.
  • The most visible transitions, and still calm: one beat, then still.
  • Room for cause, fix and a button without drawing a diagram.

Risks

  • Least distinctive mark: rings and dots are common in the menu bar, and a solid dot can read as a recording light.
  • Same custom-window cost as B, and the same Linux fallback.
  • Ink buttons ignore the system accent colour.
